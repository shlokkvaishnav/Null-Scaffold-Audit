# docs/research/

**Purpose:** Mathematical background, literature review, and evaluation methodology.

**Contains:** Derivations, references, methodology notes, and threats-to-validity analyses supporting the scientific claims made anywhere in this repository.

**Does not contain:** Results. Results are generated artifacts and live in `benchmarks/` and `experiments/`.

**Governing rule:** Every research module documents its baseline comparisons including the trivial baseline, and its data splits with justification (BOOTSTRAP.md section 13).
