# docs/adr/

**Purpose:** Architecture Decision Records — the decision, and why the alternatives lost.

**Contains:** `ADR-NNNN-short-title.md`, numbered sequentially and never reused. Use `TEMPLATE.md`.

**Does not contain:** Anything still under debate.

**Governing rule:** ADRs are immutable once accepted. A decision that changes is superseded by a new ADR that names the one it replaces — never edited in place. Constitution Article 2: a decision that exists only in the code has not been made, it has merely happened.
