# docs/rfc/

**Purpose:** Requests for Comments — proposed architecture, open for challenge.

**Contains:** `RFC-NNNN-short-title.md`, numbered sequentially and never reused. Use `TEMPLATE.md`.

**Does not contain:** Decisions. An RFC proposes; an ADR decides.

**Governing rule:** An RFC exists to be argued with. Where an RFC records no considered alternatives, review returns it (BOOTSTRAP.md section 15). An RFC that no one challenged is not thereby validated — it may simply not have been read.
