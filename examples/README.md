# examples/

**Purpose:** Worked examples for plugin and algorithm authors.

**Contains:** Minimal, runnable, tested examples showing how to implement each contract.

**Does not contain:** Examples that are not run in CI. An example that has silently stopped working is worse than no example.

**Governing rule:** These examples are the practical form of the SDK's compatibility commitment. When a contract changes, these break first, deliberately.
