# papers/

**Purpose:** Publication drafts and the regenerable artifacts they cite.

**Contains:** Manuscript sources, and the pipeline that regenerates every figure and table they reference.

**Does not contain:** Figures or tables whose generating command no longer exists.

**Governing rule:** A paper in this repository must be rebuildable from a clean checkout. Where the manuscript and the generated evidence disagree, the manuscript is the defect.
