# experiments/

**Purpose:** Experiment definitions and their recorded results.

**Contains:** Declarative experiment records — configuration, environment, seed, git SHA, hardware, and outputs.

**Does not contain:** Scripts that happened to run once. An experiment is a record, not a procedure.

**Governing rule:** Constitution Article 3. An experiment that cannot be regenerated from its recorded configuration, environment, and seed is not a result — it is an anecdote, and it is reported as one or not at all.
