# tools/

**Purpose:** Repository tooling — the checks that enforce this project's rules mechanically.

**Contains:** Static checks, code generation, and repository hygiene tooling run by CI.

**Does not contain:** Anything shipped to users.

**Governing rule:** A rule that depends on reviewer attention is a rule that erodes (VISION.md section 6). Everything in this directory exists to move a rule from convention into enforcement.
