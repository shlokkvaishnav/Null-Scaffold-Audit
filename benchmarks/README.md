# benchmarks/

**Purpose:** Benchmark suite definitions and the result artifacts they generate.

**Contains:** Suite definitions, and the generated outputs that every published number traces back to.

**Does not contain:** Results edited by hand after generation.

**Governing rule:** Constitution Article 14. Negative results are reported with the same prominence as positive ones. A method that does not beat its baseline is documented as not beating its baseline, in the same table, without softening.
