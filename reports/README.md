# reports/

**Purpose:** Publication-quality artifact generation from recorded experiments.

**Contains:** The code that turns recorded experiment outputs into tables, summaries, and paper-ready artifacts.

**Does not contain:** Hand-authored numbers, ever.

**Governing rule:** Constitution Article 13. Every benchmark number, comparison table, and performance statistic is a generated artifact produced by a documented command. A number typed into prose by a human is a defect, regardless of whether it happens to be correct today.
